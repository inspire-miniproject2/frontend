# MinwonON Frontend

민원온 공공 민원 통합 플랫폼의 React + TypeScript 프론트엔드입니다.

## 기술 스택

- React
- TypeScript
- Vite
- KRDS React (`krds-react`)

## 실행

```bash
pnpm install
pnpm dev
```

## 검증

```bash
pnpm typecheck
pnpm build
```

## 디자인 기준

- KRDS 구조와 컴포넌트 및 디자인 토큰 사용
- 1440px 데스크톱 기준, 1024px 반응형 지원
- 상태는 색상과 텍스트를 함께 사용
- 키보드 포커스와 논리적인 제목 구조 유지
